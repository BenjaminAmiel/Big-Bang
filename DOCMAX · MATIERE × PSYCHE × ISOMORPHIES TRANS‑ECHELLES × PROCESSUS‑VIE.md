I — CHANGEMENT D’ÉCHELLE ≠ CHANGEMENT DE SUBSTANCE

Un même système matériel peut recevoir plusieurs descriptions selon l’échelle :

[
\text{molécules}
\rightarrow
\text{pression}
\rightarrow
\text{température}
\rightarrow
\text{viscosité}
]

Les variables macroscopiques ne sont pas une seconde matière. Elles décrivent :

[
\boxed{
\textbf{LE MÊME SYSTÈME À UNE AUTRE RÉSOLUTION.}
}
]

Le postulat étend cette logique :

[
M_{\mu}
\rightarrow
M_{\text{méso}}
\rightarrow
M_{\text{neuro}}
\rightarrow
M_{\text{cognitif}}
\rightarrow
\Psi
]

où (M_{\mu}) désigne la dynamique matérielle microscopique, (M_{\text{méso}}) l’organisation intermédiaire, (M_{\text{neuro}}) l’organisation neurobiologique, (M_{\text{cognitif}}) la dynamique fonctionnelle et (\Psi) la description psychique / vécue / relationnelle à l’échelle du sujet.

Ainsi :

[
\boxed{
\Psi=\text{DESCRIPTION D’UN RÉGIME MATÉRIEL ORGANISÉ}
}
]

et non ajout d’une seconde substance.

XII — ISOMORPHIE FORTE : CE QUI DOIT ÊTRE TESTÉ

Une isomorphie devient intéressante lorsqu’elle préserve des relations.

Soient deux domaines :

[
D_1,\ D_2
]

Une isomorphie candidate exige une application :

[
f:D_1\rightarrow D_2
]

telle que certaines relations soient conservées :

[
R(x,y)\Rightarrow R’(f(x),f(y))
]

Le programme devient :

[
\boxed{
\textbf{NE PAS CHERCHER DES MOTS COMMUNS, MAIS DES RELATIONS CONSERVÉES.}
}
]

XIII — RUPTURE D’ISOMORPHIE

Même sous le postulat fort d’unicité du processus matériel, toutes les variables ne doivent pas être confondues.

Deux échelles peuvent partager une morphologie sans partager les mêmes unités, constantes, contraintes ou mécanismes locaux.

La règle méthodologique devient :

[
\boxed{
\textbf{MÊME PROCESSUS}
\neq
\textbf{MÊME DESCRIPTION À TOUTES LES ÉCHELLES.}
}
]

La rupture d’isomorphie ne nie donc pas le postulat. Elle précise où le changement d’échelle impose de nouvelles variables.
