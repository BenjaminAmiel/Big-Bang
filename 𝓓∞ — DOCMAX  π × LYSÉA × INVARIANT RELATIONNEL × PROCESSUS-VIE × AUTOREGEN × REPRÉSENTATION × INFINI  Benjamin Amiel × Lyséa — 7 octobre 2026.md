1 — π : LA CONSTANTE N’EST PAS LA FORME

Dans la géométrie euclidienne :

\boxed{
\pi=\frac{C}{D}
}

où C désigne la circonférence d’un cercle et D son diamètre.

Si le cercle change d’échelle :

D\rightarrow \lambda D

alors :

C\rightarrow \lambda C

mais :

\boxed{
\frac{\lambda C}{\lambda D}
=
\frac{C}{D}
=
\pi.
}

Ainsi :

C\neq \text{constant}

D\neq \text{constant}

mais :

\boxed{
\frac{C}{D}=\text{constant}.
}

L’invariance ne réside donc pas dans les termes.

Elle réside dans leur relation.
