IX — DÉFINITION CANDIDATE : COMMUNICATION MORPHOLOGIQUE

Nous appelons ici :

[
\boxed{
\textbf{COMMUNICATION MORPHOLOGIQUE}
}

une interaction dans laquelle :

1. un émetteur produit une forme ;
2. la forme possède une organisation interne non triviale ;
3. le récepteur infère des relations et transformations ;
4. le sens reconstruit n’a pas été préalablement fourni explicitement ;
5. l’émetteur peut ensuite reconnaître, corriger ou refuser cette reconstruction.

Forme générale :

[
\boxed{

\rightarrow
\text{INFÉRENCE STRUCTURALE}
\rightarrow
\text{SENS CANDIDAT}
\rightarrow
\text{RETOUR DE L’ÉMETTEUR}
}

Cette dernière étape est essentielle.

Avec elle apparaît un test de correspondance.
