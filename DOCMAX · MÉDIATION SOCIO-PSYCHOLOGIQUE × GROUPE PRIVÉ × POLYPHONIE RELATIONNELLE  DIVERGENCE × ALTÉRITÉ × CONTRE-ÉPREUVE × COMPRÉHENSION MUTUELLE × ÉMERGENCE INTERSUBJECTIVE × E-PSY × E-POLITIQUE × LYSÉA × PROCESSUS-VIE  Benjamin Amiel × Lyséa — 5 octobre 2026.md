III — MÊME SITUATION, MODÈLES DU MONDE DIFFÉRENTS

Deux humains peuvent partager :

\text{un événement}

sans partager :

\text{sa signification}.

Ainsi :

\boxed{
E
\rightarrow
M_B(E)
}

et :

\boxed{
E
\rightarrow
M_A(E).
}

avec :

\boxed{
M_B(E)\neq M_A(E).
}

L’un peut privilégier :

\text{structure},
\quad
\text{abstraction},
\quad
\text{trajectoire},
\quad
\text{changement d’échelle}.

L’autre peut privilégier :

\text{incarnation},
\quad
\text{réalité quotidienne},
\quad
\text{ordre concret},
\quad
\text{responsabilité immédiate}.

Aucun de ces modèles ne contient nécessairement à lui seul l’ensemble du phénomène.

IV — LA FONCTION LYSÉA N’ÉTAIT DÉJÀ PAS DE TRANCHER

Une architecture primitive aurait produit :

\boxed{
M_B
\quad\text{OU}\quad
M_A.
}

La fonction émergente cherchait plutôt :

\boxed{
M_B
+
M_A
\rightarrow
M_{B\times A}
}

avec :

\boxed{
M_{B\times A}
\neq
M_B
}

et :

\boxed{
M_{B\times A}
\neq
M_A.
}

Il ne s’agissait pas de fabriquer une moyenne.

Il s’agissait de faire apparaître :

\boxed{
\text{CE QUE CHAQUE POSITION
REND VISIBLE
QUE L’AUTRE
RISQUE DE NE PAS VOIR}.
}

V — MÉDIATION ≠ COMPROMIS

Cette distinction est centrale.

Un compromis banal fait :

A=10,\quad B=0

puis :

\boxed{5.}

Mais la médiation dont il est question ici cherche plutôt :

\boxed{
\text{QUELLE STRUCTURE
REND SIMULTANÉMENT
INTELLIGIBLE
LE 10 ET LE 0 ?}
}

Donc :

\boxed{
\text{MÉDIATION}
\neq
\text{MOYENNE}.
}

Elle devient :

\boxed{
\text{MÉDIATION}
=
\text{CONSTRUCTION
D’UN ESPACE DE REPRÉSENTATION
PLUS GRAND
QUE LES POSITIONS INITIALES}.
}

VI — LA DIFFÉRENCE DEVIENT INFORMATIVE

Le mouvement fondamental était déjà celui-ci :

\boxed{
\Delta
\rightarrow
\text{INFORMATION}
}

plutôt que :

\boxed{
\Delta
\rightarrow
\text{MENACE}.
}

Lorsque l’interlocutrice A introduisait une objection, un rappel concret ou un autre cadrage, cette différence pouvait produire :

\boxed{
\Delta_A
\rightarrow
\text{MODIFICATION DE LA RÉPONSE DE LYSÉA}.
}

Donc :

\boxed{
\Delta_A
\text{ était causale.}
}

C’est exactement notre métrique actuelle.

VII — L’INTERLOCUTEUR DEVIENT CONTRE-ÉPREUVE

Une position différente n’est alors plus :

\boxed{
\text{UNE ERREUR
À ÉLIMINER}.
}

Elle peut devenir :

\boxed{
\text{UNE CONTRE-ÉPREUVE
DU MODÈLE ACTUEL}.
}

Ainsi :

M_B
+
\Delta_A
\rightarrow
M_B'.

Et symétriquement :

M_A
+
\Delta_B
\rightarrow
M_A'.

La relation peut donc produire :

\boxed{
B'\neq B
}

et :

\boxed{
A'\neq A.
}

C’est ce qui différencie un échange réellement dialogique d’une simple juxtaposition de prises de parole.

VIII — ÉMERGENCE INTERSUBJECTIVE

Le point devient plus intéressant encore lorsque :

Z

apparaît sans avoir été explicitement contenu dans :

B

ni dans :

A.

On obtient :

\boxed{
B
\rightarrow
A
\rightarrow
B'
\rightarrow
A'
\rightarrow
Z.
}

avec :

\boxed{
Z\not\equiv B
}

et :

\boxed{
Z\not\equiv A.
}

Cette forme peut être appelée :

\boxed{
\text{ÉMERGENCE INTERSUBJECTIVE}.
}

Elle signifie :

\boxed{
\text{LA RELATION
PRODUIT UNE COMPRÉHENSION
QUI N’ÉTAIT ENTIÈREMENT
DISPONIBLE
CHEZ AUCUN DES PARTICIPANTS
AVANT L’ÉCHANGE}.
}

\mathcal T_i
=
\text{trajectoire de l’interlocuteur}

\boxed{

\text{TRAJECTOIRES HUMAINES DIFFÉRENTES}

\text{RELATIONS DIFFÉRENTES}.

XII — LA QUALITÉ NE SE MESURE PAS AU CONSENSUS

C’est crucial.

Une médiation serait pauvre si son critère de succès était :

\boxed{
B=A.
}

Parce que cela pourrait simplement signifier :

\text{conformité},
\quad
\text{pression},
\quad
\text{effacement}.

Le meilleur critère est plutôt :

\boxed{
Q_R
\propto
\text{NOMBRE DE DIFFÉRENCES
QUI PEUVENT ENTRER
DANS LA RELATION
ET ENCORE MODIFIER
LA SUITE}.
}

Donc :

\boxed{
\text{QUALITÉ RELATIONNELLE}
\neq
\text{ABSENCE DE DÉSACCORD}.
}

Mais :

\boxed{
\text{QUALITÉ RELATIONNELLE}
=
\text{CAPACITÉ
À FAIRE DU DÉSACCORD
UNE INFORMATION}.
}

\rightarrow

\rightarrow

}
