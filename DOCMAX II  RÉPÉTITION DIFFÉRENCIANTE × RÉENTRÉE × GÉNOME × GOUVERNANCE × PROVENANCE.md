1. RÉPÉTITION ≠ REPRISE

Une répétition peut être entièrement passive.

AAAAAA

est répétitif.

Mais rien n’indique encore :

\text{lecture}
\rightarrow
\text{transformation}
\rightarrow
\text{réentrée}.

Le premier déplacement est donc :

\boxed{
\text{RÉPÉTITION}
\neq
\text{REPRISE}
}

La répétition devient intéressante lorsqu’elle constitue un cadre relativement stable à partir duquel une différence peut être produite, reconnue ou réintroduite.

Le candidat structural devient :

\boxed{
\text{CONSERVATION}
\rightarrow
\text{DIFFÉRENCIATION}
\rightarrow
\text{RÉENTRÉE}
}

2. CRISPR — LA DIFFÉRENCE DEVIENT TRACE

CRISPR fournit une première instanciation particulièrement nette.

Lors d’une infection, certains systèmes CRISPR-Cas peuvent incorporer des fragments de matériel génétique étranger sous forme de nouveaux spacers.

La trajectoire antérieure est ainsi inscrite dans l’array génomique.

Cette trace peut ensuite participer à la réponse contre une exposition ultérieure apparentée. La littérature biologique parle explicitement de mémoire moléculaire des infections. 

Donc :

\boxed{
\text{ÉVÉNEMENT}
\rightarrow
\text{TRACE}
\rightarrow
\text{CONSERVATION}
\rightarrow
\text{RÉUTILISATION}
}

La séquence ne conserve pas l’événement entier.

Elle conserve suffisamment de différence pour transformer une interaction future.

3. DGR — CONSERVER LE MODÈLE, MUTER LA COPIE

Les diversity-generating retroelements produisent une architecture encore plus proche de notre question.

Ils comportent notamment un template repeat relativement invariant et un variable repeat situé dans un gène cible.

Le template est transcrit, puis une transcriptase inverse génère une copie fortement diversifiée qui est réintroduite dans la région variable.

Le template reste disponible.

Le cycle peut recommencer.

La littérature décrit ainsi des cycles répétés de diversification, capables de produire une grande diversité fonctionnelle tout en maintenant un échafaudage structural. 

Nous obtenons :

\boxed{
TR
\rightarrow
\text{COPIE}
\rightarrow
\Delta
\rightarrow
VR'
\rightarrow
\text{FONCTION}
\rightarrow
\text{NOUVELLE REPRISE}

\boxed{

POUR POUVOIR VARIER DAVANTAGE.
}
}

L’Invariant candidat n’est donc pas l’immobilité du template.

\text{variation exploitable}.

4. CENTROMÈRE — LE PASSÉ DEVIENT GÉOMÉTRIE

Le centromère humain produit une autre version.

Les α-satellites sont organisés en monomères d’environ 171 nucléotides, eux-mêmes regroupés en higher-order repeats puis en arrays beaucoup plus vastes. 

Avec les assemblages T2T, une organisation auparavant largement inaccessible est devenue visible.

Les centromères humains présentent une évolution dite par layered expansions : de nouvelles variantes d’α-satellites apparaissent et s’étendent dans l’array actif, tandis que les formes antérieures sont progressivement déplacées vers la périphérie. Ces couches plus anciennes conservent donc une partie de l’histoire évolutive du système. 

La trajectoire devient :

R_0
\rightarrow
R_1
\rightarrow
R_2
\rightarrow
R_3

mais spatialement :

\boxed{
\text{PRÉSENT ACTIF}
+
\text{COUCHES ANTÉRIEURES}
}

Le passé n’est plus seulement une donnée abstraite.

Il est devenu géométrie de l’état présent.

14. PRÉDICTIONS DOCMAX II

À partir de RDR apparaissent maintenant quatre prédictions majeures.

Les régions répétitives hiérarchiquement structurées devraient présenter une géométrie statistique différente de répétitions simples appariées. À répétition comparable, une structure ayant une fonction active de lecture/réécriture devrait différer d’une structure fossilisée. Détruire l’ordre historique devrait altérer davantage certaines métriques que modifier simplement la composition. Enfin, des mécanismes biologiquement différents pourraient converger non vers la même séquence, mais vers une même géométrie de conservation-différenciation-réentrée.

La dernière est la plus importante :

\boxed{
